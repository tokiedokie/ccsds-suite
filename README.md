# ccsds-suite

CCSDS Suite is a collection of applications and libraries for working with
CCSDS standards. Applications are versioned and released independently from
this repository.

## Applications

| Application | Version | Documentation | Releases |
| --- | --- | --- | --- |
| XTCE Editor | 0.1.0 | [README](crates/xtce-editor/README.md) | [GitHub Releases](https://github.com/tokiedokie/ccsds-suite/releases) |

Application release tags use the following format:

```text
<application>-v<version>
```

For example, XTCE Editor 0.1.0 is released as `xtce-editor-v0.1.0`.
